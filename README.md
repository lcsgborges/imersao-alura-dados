# Imersão de Dados - Alura

Repositório criado durante a **Imersão de Dados da Alura** para aprendizado em análise e visualização de dados.  
Foram utilizados **Pandas**, **Plotly** e **Streamlit** para manipular dados, gerar gráficos interativos e criar dashboards.

Deploy da aplicação: https://imersao-alura-dados.streamlit.app/
